# Latihan OOP PHP dan Composer

Project praktikum OOP PHP menggunakan Composer dengan autoload PSR-4.

## Materi
- Class dan Object
- Encapsulation
- Inheritance
- Interface
- Composer Autoload PSR-4

## Cara Menjalankan
1. Pastikan PHP dan Composer sudah terinstal.
2. Masuk ke folder latihan-oop.
3. Jalankan perintah composer install.
4. Jalankan php index.php.

## Struktur Project
- src/Contracts: Interface
- src/Models: Class Mahasiswa, Pengguna, Admin, dan Dosen
- index.php: Contoh penggunaan class
